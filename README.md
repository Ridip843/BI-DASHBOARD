# 📊 Ecommerce Sales Dashboard | Power BI

An interactive **Power BI dashboard** built to analyze ecommerce sales data and provide actionable business insights through dynamic visualizations and KPI tracking.

## 🚀 Overview

This dashboard helps monitor sales performance, profit, customer trends, product performance, and regional sales using interactive charts and filters. It enables businesses to make data-driven decisions quickly.

## 📌 Key Metrics

- 💰 Total Sales: **438K**
- 📈 Total Profit: **37K**
- 📦 Quantity Sold: **5,615**
- 🛒 Average Order Value: **121K**
